# cs2pay

Выкуп скинов CS2 по рыночной цене. Node.js 18+, база PostgreSQL (или файл при локальном запуске).

## Render
1. Залей папку в GitHub (без .env и data.json).
2. Render → New → Web Service → репозиторий. Build Command: `npm install`. Start Command: `node server.js`.
3. Render → New → PostgreSQL (создай базу), скопируй Internal Database URL.
4. В Environment сервиса добавь:
   - `DATABASE_URL`: URL базы из шага 3 (без неё данные пропадут при перезапуске!)
   - `BOT_TOKEN`: НОВЫЙ токен из @BotFather (старый из чата отзови)
   - `ADMIN_CHAT_ID`: напиши боту /start, он покажет ID
   - `CRYPTO_PAY_TOKEN`: токен приложения из @CryptoBot (Crypto Pay → Create App). Пополнение баланса идёт только через Crypto-бот и зачисляется автоматически после оплаты счёта
   - `GOOGLE_CLIENT_ID`: по желанию, для входа через Google
5. Проверка: открой `https://твой-сайт.onrender.com/api/health`. Там видно число скинов, тип базы и ошибку загрузки, если есть.

## Что есть
Главная, маркет с фильтрами, корзина, регистрация и вход (логин или Google), профиль: баланс, кошелёк (вывод TRC20 / Crypto-бот / карта; пополнение только через Crypto-бот), история, трейд-ссылка, смена пароля, 2FA (TOTP, Google Authenticator).
Продажа: заявка приходит в Telegram, кнопка «Принять», через 7 дней сумма сама зачисляется на баланс. Вывод подтверждаешь кнопками в боте, пополнение зачисляется само. Админ-команды бота: /help.
Трейды со скинами и сами выплаты ты делаешь вручную, сайт их не автоматизирует.
